# ADR index

> ADRs now go in `active/` and `superseded/`, and `cargo xtask adr list` replaces this index. A
> follow-up PR for [#3](https://github.com/bgillesp/math-workbench/issues/3) removes it.

Accepted ADRs are listed under "In force", grouped by area, and every other ADR under "History".
`cargo xtask check-docs` keeps the index complete. The
[architecture and design guide](../../guides/architecture-and-design.md#architecture-decision-records)
covers how ADRs are written and superseded.

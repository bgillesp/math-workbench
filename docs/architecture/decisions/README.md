# Architecture decision records

An ADR records one decision that is hard to reverse and shapes downstream work, such as the wire
type system or serialization versioning, along with the alternatives that were weighed. A
question that's still open stays in an issue until it's decided, and a choice that's local or
easy to reverse belongs in a design doc.

ADRs are numbered in sequence and cited as `ADR-0003`. Start a new one from
[TEMPLATE.md](TEMPLATE.md) with the next unused number. An accepted ADR is never edited. To
revisit a decision, write a new ADR that supersedes it and restates whatever still holds, so the
current decision for an area can be read from one document. The statuses are listed in
[docs/README.md](../../README.md#statuses).

This index lists accepted ADRs under "In force", grouped by area, and every other ADR under
"History". `cargo xtask check-docs` keeps it complete.
